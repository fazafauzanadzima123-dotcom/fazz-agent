Bilang saja.Fazz yang kerjakan.

Fazz Agent adalah asisten AI untuk HP Android. Ketik atau ucapkan permintaanmu, lalu Fazz mengecek jadwal, membuka aplikasi, memasang timer, atau mencari di web. Untuk hal yang menyangkut data pribadi, Fazz selalu minta izin dulu.

Unduh APK Lihat kode di GitHub

Versi 0.3.0 untuk Android 8 ke atas, ukuran 21 MB. Gratis dan open source (MIT).

Kamu tetap pegang kendali

Asisten yang bisa bertindak di HP harus bisa dipercaya. Ini aturan yang dipegang Fazz.

Minta izin sebelum bertindak

Data kalender dan kontak hanya dikirim ke Gemini setelah kamu menekan Izinkan. Membuat acara dan berbagi teks selalu lewat aplikasi aslinya, jadi kamu yang menekan tombol terakhir.

Tidak ada kunci di dalam aplikasi

API key Gemini disimpan di server, bukan di APK. Aplikasi berkomunikasi lewat HTTPS dan tidak bisa menjalankan kode sembarangan di HP-mu.

Chat dan memori tetap di HP

Riwayat percakapan dan memori disimpan di penyimpanan pribadi aplikasi. Password, PIN, dan nomor kartu otomatis ditolak untuk disimpan.

Pasang dalam tiga langkah

Fazz belum ada di Play Store, jadi dipasang langsung dari file APK.

  1. Unduh APK

    Buka halaman ini di HP Android, lalu tekan Unduh APK.

  2. Izinkan pemasangan

    Buka file yang terunduh. Jika Android bertanya, aktifkan “Izinkan dari sumber ini” untuk browsermu.

  3. Mulai bicara

    Buka Fazz Agent, lalu coba ketik “Berapa persen baterai HP-ku?” atau tekan ikon mikrofon.

Tanya jawab

Apakah Fazz gratis?

Ya. Aplikasinya gratis dan kodenya terbuka. Fazz memakai kuota gratis Google Gemini, jadi tiap perangkat punya batas permintaan harian.

Kenapa Android memberi peringatan saat memasang?

Karena APK ini dipasang di luar Play Store. Itu peringatan standar Android untuk semua aplikasi yang dipasang langsung. Kode lengkapnya bisa kamu periksa di GitHub.

Apakah Fazz selalu mendengarkan?

Tidak. Mikrofon hanya aktif saat kamu menekan ikon mikrofon, dan layar menampilkan tanda “mikrofon aktif”. Panggilan suara seperti “Hai Fazz” belum tersedia.

Apakah butuh internet?

Ya. Jawaban dibuat oleh Google Gemini lewat server Fazz, jadi butuh koneksi internet.

Bisakah Fazz mengirim pesan atau membayar sesuatu atas namaku?

Tidak. Fazz bisa menyiapkan teks lalu membuka menu berbagi, tapi kamu sendiri yang memilih aplikasi dan menekan kirim. Fazz tidak punya akses ke pembayaran.
